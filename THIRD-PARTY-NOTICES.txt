-------------------------------------------------------------------------------
Only in some packages
-------------------------------------------------------------------------------
Windows (Visual C++ builds): the ZIP carries Microsoft's Visual C++ runtime
DLLs (msvcp140*.dll, vcruntime140*.dll), redistributed as Microsoft permits
for its Visual C++ Redistributable files. They are Microsoft's, not covered
by lrr-portable's licence.

Windows (MinGW-w64 builds): the program links the GCC runtime libraries
(under the GCC Runtime Library Exception) and MinGW-w64's winpthreads
(MIT licence, https://www.mingw-w64.org) statically, and SDL3.dll ships
beside it.

Android (the APK): SDL3's Java classes and libSDL3.so (zlib, above) and
LLVM's libc++ (libc++_shared.so; Apache License 2.0 with LLVM Exceptions,
https://llvm.org/LICENSE.txt) ship inside it.

Nintendo 3DS (.3dsx and .cia): the program links devkitPro's libctru and
citro3d (both under the zlib licence, as SDL's text above, with their
authors' copyright: https://github.com/devkitPro/libctru and
https://github.com/devkitPro/citro3d), and devkitARM's newlib C library and
GCC runtime libraries (newlib's permissive licences, and the GCC Runtime
Library Exception).

Linux AppImage: the image starts through the AppImage type 2 runtime
(MIT licence, https://github.com/AppImage/type2-runtime).

Linux Flatpak: the freedesktop runtime and its FFmpeg extension are
installed separately by Flatpak and are not part of the package.


-------------------------------------------------------------------------------
Not included: FFmpeg
-------------------------------------------------------------------------------
The game's movies play through FFmpeg 7 or newer (https://ffmpeg.org), which
lrr-portable loads at run time when it is installed on your system. No
package includes FFmpeg; your copy comes under its own licence.
