# Finding 437 — Menu Widgets and Menu Rendering

This finding connects the assigned 42 menu functions into a config-built widget tree, modal input/render loop, and front-end transition path. Behavior summaries follow checked-in pseudocode; links to earlier findings give deeper caller and evidence details. The meanings of undocumented record fields and several widget kinds remain unresolved.

Evidence convention: descriptions of explicit calls, branches, field accesses, constants, and resource operations are direct observations from the checked-in pseudocode and linked earlier findings. Labels such as “widget,” “menu-owned,” and “transition boundary” are interpretations of those operations and surrounding callers; undocumented field meanings and the purpose of opaque values remain inferences where noted as unresolved.

## Menu construction and resource lifetime

`MenuParamRecordCreate @ 0x004105f0` allocates a `0x5c`-byte parameter record and stores the parsed menu parameters. `MenuItemChoiceStringsAllocate @ 0x00410a10` allocates a choice descriptor and a zeroed string-pointer array; `MenuItemNumericRangeRecordAllocate @ 0x00410bf0` creates a numeric range record only when its upper bound exceeds its lower bound. `MenuTextRecordMake @ 0x00410d50` and `MenuButtonRecordMake @ 0x00410e20` construct the text and button item variants, while `MenuItemImageSet @ 0x00410fb0` resolves and stores an image resource. `MenuSectionRecordCreate @ 0x00411100` builds a menu section record. These are used by the config-driven `MenuBuild @ 0x004140c0` parser described in [Finding 23](23-front-end-and-menu.md); [Findings 253](253-terrain-scatter-erosion-propagation-cell-queries-menu-records-and-buffer-helpers.md), [276](276-additional-engine-ui-and-scene-helper-names.md), and [393](393-string-list-and-small-record-utilities.md) describe allocation and ownership details.

`MenuItemRecordAlloc @ 0x00413f90` allocates the generic item record and classifies its image path; `MenuItemType @ 0x00413e60` reads the record's type. `MenuRecordResourcesRelease @ 0x00410690` releases menu-owned resources, and `OptionalResourceDestroy @ 0x0040f7b0` conditionally frees a non-null resource. `MenuListFindName @ 0x00414c90` scans a list and returns the case-insensitive matching entry index, or `-1`. `SavMenuList @ 0x004179b0` builds/updates the save-menu list. Existing traces are in [Findings 356](356-animation-and-low-address-state-helpers.md), [393](393-string-list-and-small-record-utilities.md), [23](23-front-end-and-menu.md), and [253](253-terrain-scatter-erosion-propagation-cell-queries-menu-records-and-buffer-helpers.md).

## Input, hit testing, and widget state

`MenuPointerRectangleHitTest @ 0x004112e0` tests pointer coordinates against a rectangle; `MenuMouseCoordinateUpdate @ 0x00411360` refreshes the stored mouse coordinates. `MenuWidgetItemScreenRect @ 0x00411530` resolves an item's clickable screen rectangle, and `MenuPickWidgetUnderPointer @ 0x00411790` scans menu items and returns the hit widget. `MenuInputTick @ 0x00411a00` dispatches mouse/keyboard actions for the current menu and returns early while a wipe is active. `MenuSliderPointerHandler @ 0x00411870` hit-tests the slider thumb and arrow regions, then writes or increments/decrements the stored slider value; its pseudocode does not call a change handler. `FrontendProgressValueChanged @ 0x00411840` separately compares the current progress value with its previous value and updates the saved value. [Findings 23](23-front-end-and-menu.md), [24](24-menu-wipe-and-front-end-transition.md), [240](240-cursor-interaction-overlay-menu-and-scene-light-helpers.md), and [374](374-terrain-interface-and-media-helpers.md) trace these paths.

`MenuScrollStateUpdate @ 0x00413970` advances or clamps the menu scroll state; `ScrollToSliderIndexStore @ 0x00414f90` maps the current game-speed float into the stored discrete slider index; `ScrollToSliderIndex @ 0x00415030` performs the reverse threshold mapping; and `ScrollSliderRefresh @ 0x00415360` stores the current mapped index. `ScrollToSliderIndex` uses thresholds `2/3`, `1`, `4/3`, `5/3`, and `2` to map the continuous value to indices 0–5. `ScrollInfoPanelInitialize @ 0x0045b740` belongs to the adjacent simulation info-panel path and initializes its scroll rectangles/widget; see [Finding 262](262-scroll-panel-and-viewport-picking-helpers.md). The slider helpers and broader options flow are described in [Finding 23](23-front-end-and-menu.md).

## Modal menu loop, transition, and overlays

`MenuEnter @ 0x00416c80` selects/enters a menu; `MenuWipeStart @ 0x004103f0` and `MenuWipeEnd @ 0x00410440` start and clear the configured LWS transition state. `MenuRunLoop @ 0x00413b80` repeatedly calls `MenuTick @ 0x00412c00`, which updates the current menu and any overlays; `MenuShow @ 0x00413e20` resets item selection flags before entering that loop. `OverlayMenuGate @ 0x00415370` gates overlay-menu activity against current menu and game state. `MainMenuTextItem @ 0x004103d0` routes the main menu's credits/text item to the scrolling-text display. The transition/input state machine and callers are traced in [Findings 23](23-front-end-and-menu.md) and [24](24-menu-wipe-and-front-end-transition.md).

`MenuOverlayListCount @ 0x00412170` counts configured overlay records, while `MenuOverlayFlicPlaybackController @ 0x004121b0` selects/plays an overlay FLIC when its random-play gate allows it. `MenuAudioTickIntervalReached @ 0x00412190` tests the audio timer against a 400-unit interval. `MenuSaveImageConfigRectBlit @ 0x004124f0` reads the configured save-image rectangle and blits its image; `MenuHoverStatusTextDraw @ 0x00412750` draws hover/status text for the focused menu window. `MenuOverlaySurfaceAndTextSetup @ 0x004129d0` sets up overlay surfaces and text, and `MenuSurfaceBlitScaled @ 0x00412af0` performs scaled menu-surface blits. See [Findings 23](23-front-end-and-menu.md), [141](141-menu-overlay-streams-submit-on-state-zero.md), [246](246-entity-move-route-command-and-object-clone-helpers.md), [245](245-region-route-light-config-and-surface-helpers.md), [253](253-terrain-scatter-erosion-propagation-cell-queries-menu-records-and-buffer-helpers.md), [252](252-config-band-texture-loaders-route-commands-and-surface-menu-helpers.md), and [372](372-incident-messages-options-and-resource-helpers.md).

## Menu-specific callbacks and neighboring flows

`OptionMusicDefault @ 0x00414e10` returns the music option default. `InterfaceMenuActionLabelsInit @ 0x0041a300` initializes menu-action labels; `MenuSelectionResourceUpdate @ 0x0041b300` updates a resource value from the selected menu category; `TutorialPathMenuAction @ 0x0041d040` dispatches tutorial-path interaction; and `MenuOptionPanelTextureUpdate @ 0x004355c0` updates the option panel's texture state. `PanelSelectionHighlightToggle @ 0x00435aa0` toggles a panel item, plays its activation sound, and starts a short timer. These helpers sit across menu, tutorial, and panel boundaries; [Findings 23](23-front-end-and-menu.md), [254](254-command-sweeps-cell-issuing-config-priorities-statistics-and-directdraw-create-helpers.md), [380](380-scene-objects-terrain-and-matrix-helpers.md), [241](241-terrain-quad-run-upgrade-and-scene-slot-helpers.md), and [386](386-spatial-ui-com-and-crt-runtime.md) carry their caller contexts.

`MenuWipeStart/End`, `MenuInputTick`, and the modal loop form a clear transition boundary: a menu change starts the wipe, the input tick is suppressed while its active bit is set, and the end helper clears the wipe bits. The strongest follow-up areas are resolving menu-item record ownership through teardown, documenting the remaining widget-kind-specific fields, and tracing which config entries feed tutorial-path actions and option-panel texture changes. Meanings of generic flags and nonstandard slider/menu records remain open.

Complete pseudocode is in [LEGORR.full.c](../decompiles/full/LEGORR.full.c), with named excerpts in [engine-region.c](../decompiles/legacy/engine-region.c).
