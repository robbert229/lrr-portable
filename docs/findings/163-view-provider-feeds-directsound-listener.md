# Finding 163 — A Stored View Provider Feeds DirectSound Listener State

`FUN_0047ab80` stores a view-related object in `DAT_00506688` when sound is initialized. The level setup path and the two view-mode branches in `FUN_004295f0` call this setter with objects selected from the current level/view records. `FUN_0047aba0` checks that sound is active and a provider is stored, then calls `FUN_0047abc0`.

The helper reads three-vector values from the stored object through its vtable, compares the values against cached vectors, and updates the acquired DirectSound 3D listener when they differ. The listener receives a position through vtable slot `+0x38` and an orientation through `+0x34`; the helper then calls slot `+0x44` to commit deferred changes. The slot identities align with the `IDirectSound3DListener` interface, where finding 62 separately maps slot `+0x3c` to the rolloff setter.

This identifies the data source and the listener properties written by the helper. The frame-tick entry `LAB_004232e0` calls `FUN_0047aba0` once per tick, after other level-update calls. Finding 02 traces that label as the registered frame callback. The meaning of the provider's individual vectors and their units are not named by the decompile.

**Evidence.** Static decompile and disassembly of shipped `reference/LegoRR.exe`, SHA-256 `c3d8ce23f1aa21814950c77e713ec176599506d4e71758cf1cf709525e581e0f`: `FUN_0047ab80` at `0x47ab80` stores the provider; `FUN_0047aba0` at `0x47aba0` gates and dispatches the update; `FUN_0047abc0` at `0x47abc0` reads/caches vectors and calls the listener. The frame-tick label `LAB_004232e0` calls `FUN_0047aba0` at `0x423670`; finding 02 traces `LAB_004232e0` as the engine's registered frame callback. Level setup at `FUN_0041fb50` and view-mode transitions at `FUN_004295f0` select providers. The listener interface acquisition is documented in finding 119; the rolloff setter and its clamp are documented in finding 62. Microsoft lists the [IDirectSound3DListener8 interface methods](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ee418003%28v%3Dvs.85%29), including position, orientation, and deferred-settings commit.
