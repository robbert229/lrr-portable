# Finding 164 — Explicit Sound Positions Apply Immediately

The explicit-position route traced in finding 161 reaches `FUN_0047ad70` in mode 1. That branch calls `FUN_0047ad10` with the selected 3D buffer and the caller's three-float position. `FUN_0047ad10` invokes the buffer vtable slot `+0x4c` with those coordinates and a final `0` apply flag. The slot corresponds to `IDirectSound3DBuffer::SetPosition`; `0` is `DS3D_IMMEDIATE`, so the requested source position is applied immediately.

After the route, `FUN_0047ad70` reaches common cleanup that calls listener slot `+0x44` before returning. Finding 119 identifies that object as the acquired DirectSound 3D listener, and the interface maps this slot to `CommitDeferredSettings`. That separate commit call does not make the explicit position write deferred. The decompile does not establish successful HRESULTs or audible output.

**Evidence.** Shipped `LegoRR.exe`, SHA-256 `c3d8ce23f1aa21814950c77e713ec176599506d4e71758cf1cf709525e581e0f`. `FUN_00465090`, `FUN_0047ad70`, and `FUN_0047ad10` are in `docs/decompiles/full/LEGORR.full.c` at `0x465090`, `0x47ad70`, and `0x47ad10`; the dispatcher and its common listener commit are also in REA record `ev_02979193ddb48091c08741d27b02a3ab17faf60623138fd8969a49fc55ae655e` in `docs/evidence/legorr-sound-instance-spatial-expansion.bundle`. The buffer vtable slot `+0x4c` is SetPosition and listener slot `+0x44` is CommitDeferredSettings from the DirectSound method layouts. Microsoft documents the [SetPosition apply flag](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ee417996%28v%3Dvs.85%29), including that `DS3D_IMMEDIATE` applies the value immediately.
