# Finding 186 — `DontPlayAvis` Gates Boot Movies but Not Other Video Paths

`FUN_00414ce0` reads the `DontPlayAvis` configuration value and returns false when it is enabled; the startup sequence uses that result to gate the `LegoAvi`, `DDIAvi`, and `RRAvi` playback calls. Two other video paths do not use this gate. The level loader calls `FUN_00415990(level, 1)`; that helper reads the level's `Video` entry and plays it when present. The credits callback `FUN_004103d0` directly calls `FUN_0040a0c0` with `CreditsTextFile`, `RSFont`, and `CreditsBackAVI`. Neither route checks `DontPlayAvis` or calls `FUN_00414ce0`, so the option does not suppress those level and credits videos. This finding bounds the observed gate coverage to the boot sequence, rather than claiming a complete inventory of every video callsite.

**Evidence.** Shipped `reference/LegoRR.exe`, SHA-256 `c3d8ce23f1aa21814950c77e713ec176599506d4e71758cf1cf709525e581e0f`. `FUN_00414ce0` at `0x414ce0` tests `DontPlayAvis`; the startup callsite gates the `LegoAvi`, `DDIAvi`, and `RRAvi` calls with that helper in `FUN_0041fb50`. Level loading calls `FUN_00415990(param_1, 1)` in `FUN_00429890` at `0x429890`; `FUN_00415990` reads `Video`, opens it, and calls the playback loop without consulting the option. The Credits callback is installed in main-menu construction and calls `FUN_0040a0c0` through `FUN_004103d0`; `FUN_0040a0c0` opens its AVI argument without consulting the option. All functions are in `docs/decompiles/full/LEGORR.full.c`.
