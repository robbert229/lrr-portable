# Finding 186 — Credits Background Bypasses the `DontPlayAvis` Gate

`FUN_00414ce0` reads the `DontPlayAvis` configuration value and returns false when it is enabled; the startup sequence uses that result to gate the `LegoAvi`, `DDIAvi`, and `RRAvi` playback calls. The credits path is separate: the main-menu callback `FUN_004103d0` directly calls `FUN_0040a0c0` with `CreditsTextFile`, `RSFont`, and `CreditsBackAVI`, and neither function checks `DontPlayAvis` or calls `FUN_00414ce0`. If the credits text and AVI paths are available, selecting Credits still reaches the movie-open call when `DontPlayAvis` is enabled. This is a path-specific exception to the option's apparent all-AVI intent; it does not establish that every AVI callsite bypasses the gate.

**Evidence.** Shipped `reference/LegoRR.exe`, SHA-256 `c3d8ce23f1aa21814950c77e713ec176599506d4e71758cf1cf709525e581e0f`. `FUN_00414ce0` at `0x414ce0` tests `DontPlayAvis`; the startup callsite gates its AVI sequence with that helper in `FUN_0041fb50`. The Credits callback is installed in the main-menu construction code and calls `FUN_0040a0c0` through `FUN_004103d0`; `FUN_0040a0c0` calls `FUN_0047ec90` for its AVI argument without consulting the option. These functions are in `docs/decompiles/full/LEGORR.full.c`; the shipped config documents `DontPlayAvis` as intended to stop AVI playback.
