# Finding 180 — CD Audio Watchdog Detects Track Overrun at Four-Second Intervals

`FUN_00489210(trackIndex)` sends the MCI command `play cdaudio from trackIndex+1`; it supplies no `to` position. Microsoft documents that an omitted MCI `to` position defaults to the end of the media. `FUN_00489280(trackIndex)` first checks whether CD audio is stopped; if still active, it reads `current track` and considers playback valid while the returned track number is less than or equal to `trackIndex+1`.

The in-game watchdog `FUN_00488c00` runs its status check when more than 4000 ms have elapsed. If playback is stopped or the current track has advanced beyond the requested track, it issues `FUN_00489210` again for the configured track. Therefore, on a disc with a following track, playback can continue into that track until a watchdog check detects the advance and restarts the configured track. The delay is bounded by the watchdog polling interval plus the caller's tick cadence; no physical CD playback was measured.
