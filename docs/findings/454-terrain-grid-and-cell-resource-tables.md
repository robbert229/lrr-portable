# Finding 454 — Terrain Grid and Cell Resource Tables

This finding maps the 17 procedures assigned by issue #158. They span terrain-descriptor lookup and cleanup, dependency-grid parsing, cell-resource filtering, tile-variant handles, visual-channel tables, cell-table access and terrain-choice selection. “Resource” and “dependency” describe the surrounding call paths and names; undocumented record fields and numeric flags remain numeric where their meaning is not established.

| Address | Procedure | Observed behavior |
| --- | --- | --- |
| `00408d70` | `TerrainDescriptorCoordinateCountLimitCheck` | Looks up a descriptor by key, counts its stored coordinate pairs matching `(x,y)`, chooses a type-specific limit from descriptor flag `+0xd0` bit 1 and helper calls, and returns whether count is below that limit. For types other than 6 or 7 it returns true once the descriptor is found. |
| `00408ec0` | `KindNineNeighborEmitForFootprintCells` | Walks a list of cell coordinates, detects footprint boundary edges, and for each cardinal neighbor outside the supplied footprint emits a kind-9 command through `FUN_00403750`; increments the descriptor’s `+0x1c` count for each emitted command. The command vector uses a scale derived from `8.8 / FUN_00450890(...)`. |
| `004090c0` | `TerrainDescriptorFindExact` | Scans the linked list at `DAT_004b8a24` (`next` at `+0x24`). A non-null first argument matches the two key dwords at `+0xc/+0x10`; otherwise a non-null second argument matches the dword at `+8`. Returns the first matching descriptor or null. |
| `00409600` | `TerrainDescriptorTilesResetAndFree` | If descriptor progress fields `+0x1c` and `+0x20` differ, clears selected terrain-cell masks/field, refreshes each stored coordinate, resets associated object state (with a special path for object type 9), dispatches a descriptor command, and frees its coordinate list through `FUN_004099f0`. |
| `0040ab70` | `DependencyGridConfigLoad` | Parses `Dependencies` entries and their child entries, resolves grid coordinates and values, writes records into `DAT_004b8c48`/`DAT_004b8c4c`, then runs `FUN_0040b1b0` to recompute the dependency-grid pass. Entry names include `HitOnceStay`; the associated flag bits remain numeric. |
| `0040aea0` | `EnsureCellEntriesLoaded` | Unless global `DAT_004c7178` is set, maps `(param_1,param_2,param_3)` to a cell record in the `0x31`-stride table. If its byte lacks bit 1, collects entries via `TerrainCellRecordGet`, validates each through `FUN_004377b0` with `CellResourceEntryMatches`, returns false on the first rejected entry, and sets bit 1 only if the record already carried bit 0. Otherwise it returns true. |
| `0040af40` | `CellResourceEntryMatches` | If `FUN_00439200(entry[0])` finds a registered object, accepts the entry. Otherwise requires entry fields 0 and 1 to match the candidate, and, when entry field 3 is nonzero, requires candidate field `+0x330` to be at least entry field 2. |
| `0040b000` | `TileMatchingCellsCollect` | Scans 300 cell-resource records as 20 row groups of 15 columns (the pointer bound spans 300 strides of `0x31` dwords). For unloaded/default records it tests one resource set; for loaded records it checks up to 16 variants. Matching entries compare two requested fields and an optional third field, then append row, column, and a default/variant marker to the caller’s output record; loaded-record matches also store the variant index. |
| `0040b310` | `LoadTileVariants` | Allocates a descriptor and a `width × height` handle array, constructs each filename as `%s%0.1x%0.1x.bmp`, loads it via `FUN_004744f0`, and stores the returned handles. Allocation failure frees the descriptor when the array allocation fails. |
| `0040b410` | `TerrainCellResourceGridDispose` | Releases each handle in a width-by-height descriptor through `FUN_00474710`, then frees its handle array and descriptor. |
| `0040b7d0` | `CellVisualChannelTableDispose` | Clears the table’s resources, releases its two leading handles through `FUN_00472a40`, then frees the table. |
| `0040b810` | `CellVisualChannelTableResourcesClear` | Resets the counter at `+0x32c`, scans two 100-entry handle arrays beginning at `+8`, releases nonzero handles through `FUN_00472a40`, and zeros each slot. |
| `0040b880` | `CellVisualChannelRelay` | Calls `FUN_00473690` twice, storing one returned handle in each persistent 100-slot channel at the current counter index. A 12-value table maps the low byte of `param_4` to two groups of three data pointers; it calls `FUN_0040ba00` twice with those groups and shared parameters, then increments the counter at `+0x32c`. Selector and channel meanings are unresolved. |
| `0040c570` | `ReadCellTablePair` | Computes a table base from `param_1` and `DAT_004c79a4`, then reads two dwords at offsets `param_2*4` and `param_2*4 + 0x10`; field meanings remain unknown. |
| `0040cdc0` | `MapCellRecordGridInitialize` | Allocates and zeroes `width × height × 0x14` bytes from dimensions at level offsets `+0x14/+0x18`, stores the level pointer in `DAT_004c7dfc`, clears 32 global dwords, and resets two counters. `MapCellStateBufferRebuild` first frees the previous cell buffer and marker resources before calling it. |
| `0040e700` | `TerrainChoiceResourceSelect` | Decodes a choice record through `FUN_00439930`; selectors 1–4 index one of four arrays, 6/7 select scalar handles, and other values clear the active handle and bit 0 of `DAT_004c7ea8`. Valid selections set bits 0–1, store the original argument, and refresh `DAT_005007dc`. |
| `00434530` | `TerrainGridEntryResourcesReleaseAll` | Walks the current level’s `width × height` entries in the array at level offset `+0x80`, calling `CellVisualChannelTableResourcesClear` for each non-null pointer. It does not free those table records. |

## Connected flows

Terrain descriptors are a linked-record system: `TerrainDescriptorFindExact` is reused by coordinate-count checks, repeated-command creation, object-group registration, selection reset, and the kind-9 boundary emitter. The descriptor stores coordinate pairs beginning at `+0x14`, count/capacity-like fields at `+0x18/+0x20`, command counters at `+0x1c/+0xcc`, and a next pointer at `+0x24`. These are observed offsets; their higher-level semantics are inferred from their use. `TerrainDescriptorTilesResetAndFree` is called from `UiActionDispatch` for action kind `0x10` when the selected cell lacks flag `0x40000000`; when that flag is set, the same branch calls `ClearSelectionGroup` instead. It clears terrain state before descriptor cleanup. `TerrainCellPredicateCheck` and `ReleaseSelectionGroupResources` also wrap exact-key lookup.

The dependency grid has separate configuration and propagation stages. `DependencyGridConfigLoad` populates cells from config and calls `DependencyGridOccupancyPass`; that pass is also called by `BuildingUpgradeStateChangedEventDispatch` and reads `EnsureCellEntriesLoaded`. `EnsureCellEntriesLoaded` shares the cell-table accessor with `TileMatchingCellsCollect`, and its callback checks are also used by the advisor catalog and overlay flows. Its portable production path resolves the selected base/variant tuple list and applies the retail filtered entity-pool predicate to every tuple; the former optional occupancy provider was removed because it bypassed that configured-record behavior. The state bits at each `0x31`-stride record remain numeric; Finding 252 documents the propagation pass’s observed bit transitions.

Tile and visual resources have distinct lifetimes. `LoadTileVariants` is called from tile-set initialization after width and height are read from texture configuration; `PendingLevelName` later releases the grid via `TerrainCellResourceGridDispose`. Visual-channel tables are used by `CellSurfaceUpdateDispatch` for qualifying terrain-cell flags and are cleared across the active terrain grid by `TerrainGridEntryResourcesReleaseAll`; the broader level teardown separately frees table records through `CellVisualChannelTableDispose`. Finding 13 traces the tile filename pattern and texture loader, Finding 254 traces the surface-update caller, and Finding 393 covers table destruction.

`ReadCellTablePair` is used by terrain-cell flag cleanup to retrieve coordinate pairs from a per-kind table before clearing several numeric cell bits. `MapCellRecordGridInitialize` is reached through `MapCellStateBufferRebuild`, which allocates a five-dword-per-cell buffer and resets marker state. `TerrainChoiceResourceSelect` is called by the simulation pointer-action dispatcher after a specific input flag path; the selected handle then feeds the interface update helper described in Finding 419.

- Identify the semantic names and ownership rules for the dependency-grid record flags and its 16 slots; the current evidence supports only the tested bit transitions and config writes.
- Resolve the selector table, cell groups, and callee contract used by `CellVisualChannelRelay`, and determine what `FUN_0040ba00` does with the selected data pointers.
- Determine the meaning of the five dwords in the map-cell record buffer and the two values returned by `ReadCellTablePair`.
- Confirm the intent of the `TerrainDescriptorTilesResetAndFree` progress/count fields and descriptor flag bit 1 from runtime evidence or stronger caller context.
