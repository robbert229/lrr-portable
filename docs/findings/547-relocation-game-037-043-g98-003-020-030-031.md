# Finding 547 — GAME-037, GAME-043, G98-003, G98-020, G98-030 and G98-031 relocated

Refs #443 #446. Stage S3 of the [#388 plan](../plans/388-original-link-order.md),
[ADR 0006](../adr/0006-original-link-order.md) decisions 3–4, entropy rules 2–3
and the reshape-commits addendum. This wave relocates the six units that
`tools/relocate_unit.py --survey` reports as relocatable as they are, on `main`
`8d548015` (after #507's reshapes, finding 542, and #510's whole conditional
groups, finding 545):

- **GAME-037** (R5, #446), unblocked by #507's `mission.cpp` macro rename (B2);
- **GAME-043** (R5, #446), `entity.cpp`'s 13 split naked heads (B1) and the
  `ENTITY_STATS_*_READ` macro group (#510);
- **G98-003** (Viewports.c), **G98-020** (Lws.c), **G98-030** (Wad.c) and
  **G98-031** (R2, #443), unblocked by #510.

## Summary

1. **All six units move**, one tool-generated commit each, in link order, with
   no hand edits. Together they move 176 functions, 17 owned globals and 85
   closure items into six new unit files, with 21 new private headers.
2. **One fix-up commit**, outside the relocations: the matching build's
   diagnostics gate (`tools/reccmp_diagnostics.py`, #479) allowed MSVC's
   C4172 only from `gods98/view.cpp`. Its one source,
   `com_property_result_get` (`0x00477310`), moved verbatim into
   `gods98/viewports.cpp` with G98-003. The allowance now names that file.
3. **Earlier units: one listing changed, and its code did not.** No earlier
   unit file or private header is edited. Of the 794 reported functions in the
   57 earlier unit files, one listing digest changes: `0x004078c0`
   (`bubbles.cpp`, GAME-005). Nothing `bubbles.cpp` compiles against changed,
   so its object is identical. Only a string literal's operand label differs.
   This is the same flip finding 541 recorded. The digest has alternated
   between the same two values in `main`'s history.
4. **25 listings change; four scores drop.** All four drops are drift
   (`drift-review` ×3, `drift-reordered` ×1). None is `source-changed`, and
   all four reproduce in a single-TU compile. **One exact match is gained**
   (`0x00476d50`, 90 → 100%). **No exact match is lost**: exact-function code
   bytes rise from 65,713 to 65,750. **The baseline is refreshed.**
5. **The 13 naked heads in GAME-043 still match.** Every `__asm` body keeps an
   identical listing digest and score (below).
6. **Layout:** function-order pair inversions fall from 289,242 to 238,597
   (−50,645), and unit contiguity rises from 84.93% (186 units) to 87.21%
   (191).
