# Finding 196 — The Listener Uses Scene-Relative Frame Vectors

The DirectSound listener update reads its provider as an `IDirect3DRMFrame3` interface. The helper first calls frame vtable slot `+0x68` (`GetScene`), then passes that returned scene frame as the reference argument to slot `+0x60` (`GetPosition`) and slot `+0x7c` (`GetOrientation`). The position, direction, and up vectors returned by those calls are passed directly to the listener's position and orientation setters; this helper applies no coordinate scaling or axis conversion.

In Direct3DRM terms, the listener position is the provider frame's position relative to its scene frame. The orientation call supplies the frame's direction and up vectors relative to that same scene frame. The documented Direct3DRM convention identifies those as the frame's z-axis and y-axis. Direct3DRM position values have no prescribed units. The binary passes them to DirectSound without conversion; finding 199 shows that DirectSound's default distance factor remains in effect, so DirectSound interprets one input vector unit as one meter. The game's intended physical size for a frame-space unit remains unknown.

This resolves the provider calculation and coordinate-reference questions left open in finding 163. It does not establish a runtime listener position, audio propagation result, or audible output.

**Evidence.** Static disassembly of shipped `reference/LegoRR.exe`, SHA-256 `c3d8ce23f1aa21814950c77e713ec176599506d4e71758cf1cf709525e581e0f`: `FUN_0047abc0` at `0x47abc0` invokes vtable slot `+0x68` with an output pointer; invokes `+0x60` with that output as the reference frame and a three-float position buffer; then invokes `+0x7c` with the same reference frame and two three-float buffers. The resulting buffers are passed without intervening coordinate arithmetic to listener slots `+0x38` (position) and `+0x34` (orientation). These offsets and argument shapes match the `IDirect3DRMFrame3` `GetScene`, `GetPosition`, and `GetOrientation` methods. The DirectX 6 [IDirect3DRMFrame3 API reference](https://library.thedatadungeon.com/directx6/dxmedia/foundation/d3drm/ref/frame3atom.content.htm) documents position relative to a reference frame, direction/up vectors, and their z-/y-axis meaning; the [SetPosition reference](https://library.thedatadungeon.com/directx6/dxmedia/foundation/d3drm/ref/frame3ntoz.content.htm) says positions have no units. Finding 199 documents the distance factor applied by DirectSound.
