# Finding 390 — Motion, Configuration, and Resource Utilities

This pass traces the 13 helpers assigned to `motion-config-utilities` from their shared motion ticker through configuration loading, UI progress state, and teardown. Names describe observed operations; animation roles, state-bit meanings, and resource types remain unresolved where callers do not establish them.

| Address | Name | Observed behavior and callers |
| --- | --- | --- |
| `0x0044d0d0` | `DriftOffsetStepApply` | Under global bit `0x1`, counts down a timer, samples a new interval, then applies a shared random factor to three offset ranges. If adding the X sample would reach or exceed its bound, it changes all three samples to their negative absolute values and retries the X check; if X still reaches or exceeds the bound, it returns without applying the offsets. Caller: `0x0044cfa0`. |
| `0x0044d250` | `FloatNegateAbsoluteValue` | Replaces a float with its negative absolute value; used by `DriftOffsetStepApply` for the fallback offsets. |
| `0x0044d280` | `RandomWaypointTimerStepApply` | Under bits `0x4` and `0x8`/`0x10`/`0x20`, samples target vectors and durations, derives per-axis velocities, advances toward or away from the target, and clears phase bits on completion. Caller: `0x0044cfa0`. |
| `0x0044d710` | `WaypointVectorRandomScaleApply` | Samples a scalar from `DAT_004eae54..58` and divides the three target-vector components by it to produce shared per-axis velocity values. Called by `RandomWaypointTimerStepApply` when a target is initialized or a wait phase ends. |
| `0x0044d760` | `JitterStepApply` | Under bit `0x40`, samples a timer, magnitude, and normalized random 3D direction; on the subsequent phase it probes the scene position plus and minus that offset with `VectorWithinAxisTolerance`, applies an accepted position, and counts down the jitter duration. Caller: `0x0044cfa0`. |
| `0x0044d9a0` | `VectorWithinAxisTolerance` | Returns true only when each component differs from a global reference by no more than its corresponding tolerance. Called twice by `JitterStepApply`; the compared vector's domain is unresolved. |
| `0x0044da20` | `RoutePositionBlockedStateSet` | Updates the shared flag word from the supplied condition: the nonzero path sets `0x200` and clears `0x400`; the zero path clears `0x200` and `0x1000`. Caller `0x00426520` supplies the failed cursor/ray target lookup condition (Finding 385). |
| `0x0044da50` | `ThreeChannelValueTweenStep` | Unless flag `0x200` selects the decreasing mode, advances three global channels by `dt * 0.1` and latches bit `0x400` when the first reaches its bound. In decreasing mode it subtracts the same amount from all channels and latches `0x1000` when the first reaches zero; that bit causes the next call to zero all three. Caller: `0x0044cfa0`; channel meanings remain unknown. |
| `0x0044db50` | `KeyValueEqualsFileLoad` | Clears 0xa4 dwords of configuration storage and initializes the associated state, including a 50-entry table of three-dword records. It opens the supplied file for reading, splits lines on `=`, duplicates each key and parses its value, then registers `FileLoadingProgressUpdate` as a callback. Caller: `GameConfigInit` (Finding 244). |
| `0x0044dd40` | `EngineLoaderProfileEntriesRelease` | Optionally emits each populated table entry to a profile file, frees its key string, closes the profile handle, and frees loader-owned file state. Called from engine shutdown; loader/profile semantics are documented in `docs/findings/03-engine-tick.md` and `379`. |
| `0x0044dde0` | `StringTableEntrySetCurrent` | With null input clears an active flag; otherwise case-insensitively selects a matching one of 50 entries or allocates a new key in the reused slot, initializes its counters, enables progress state, and requests a progress update. Callers include `GameConfigInit` and `LevelLoad` (Finding 247). |
| `0x0044dec0` | `FileLoadingProgressUpdate` | When progress display is active, increments the selected entry's counter, computes a ratio, and updates progress UI resources and optional text when the ratio advances. Registered by `KeyValueEqualsFileLoad`; also called by `StringTableEntrySetCurrent`. |
| `0x0044e0a0` | `GlobalResourceHandleRelease` | If the shared resource handle is nonzero, releases it through the resource helper and invokes cleanup. Called during engine shutdown; exact resource type and ownership source remain unknown (Finding 379). |

The four time-stepped routines (`0x44d0d0`, `0x44d280`, `0x44d760`, and `0x44da50`) are dispatched in order by `0x44cfa0`, which is itself called from `EngineTick` with frame delta. It then publishes the three shared channel values through `0x44cff0` as a clamped UI RGB color; interpreting the channels as color is supported by this adjacent caller, while their exact source configuration remains unresolved. The configuration/progress helpers share state initialized by `KeyValueEqualsFileLoad` and consumed by `StringTableEntrySetCurrent`/`FileLoadingProgressUpdate`; the two release helpers are teardown paths documented in the engine-shutdown notes.
