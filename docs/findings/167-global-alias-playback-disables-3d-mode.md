# Finding 167 — Global Alias Playback Disables DirectSound 3D Mode

For loaded in-memory sound entries, `FUN_0047ad70` calls the selected 3D-buffer interface's vtable slot `+0x48` (DirectSound `SetMode`) with apply flag `1`. Its object-attached and explicit-position branches pass mode `0`, while its global playback branch passes mode `2`. DirectSound defines these values as `DS3DMODE_NORMAL` and `DS3DMODE_DISABLE`, respectively; the apply flag `1` requests immediate application.

The callers map those branches to distinct submission routes: `FUN_00465090` dispatches object-attached requests with mode `0` and explicit-position requests with mode `1`; `FUN_00464fa0` uses mode `2` for global alias playback. Thus the two spatial routes set 3D processing to normal, while the global in-memory alias route explicitly disables it. The `@` streamed branch returns through its separate streaming path before this per-buffer mode setup. This describes interface calls, not audible results or hardware behavior.
