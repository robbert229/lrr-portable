# Finding 436 — Simulation UI and Player Controls

This finding connects the assigned 63 functions into the in-game interaction and panel-control paths. The descriptions summarize checked-in pseudocode; linked findings add caller and evidence context where available. Interpretations are marked as such, and global/table meanings stay unresolved when the code only shows mechanics.

## Panel state and simulation interaction

`ManagerTick @ 0x0045a730` updates a 12-slot positional-tracker table; the slots hold handles, target/smoothed positions, mode, and flags, with index 9 also stopping four timers. `PanelTextureSlotsBlit @ 0x0045a9c0` walks a per-panel draw-record array and blits the texture selected by each record's state bits. `PanelTextureSlotsAllocate @ 0x0045ac30` allocates and initializes those records. The connection is direct: the panel blitter's caller is `ManagerTick`, and the records share the panel tables used by the slot allocator. The slot semantics are described in [Finding 04](04-sim-input-and-events.md), and panel allocation/blitting in [Finding 250](250-config-band-loaders-cell-corner-scan-action-command-record-instantiation-and-render-state-helpers.md).

`PanelItemFlag10SetClear @ 0x0045aac0`, `PanelStateFlagsToggle @ 0x0045ab00`, `PanelItemFlag8SetIfEnabled @ 0x0045abf0`, and `GlobalUIFlags_00500860ClearBits_1_2 @ 0x0045b610` update panel item or global UI bits. `RequestRecordSetFlag4ClearFlag8 @ 0x0045ab30`, `RequestRecordSetFlag2ClearFlag8 @ 0x0045ab60`, and `RequestRecordFlag8IsSet @ 0x0045ab90` manipulate/test request-record bits; `InputDeviceSetFlag20 @ 0x0045abb0` updates bit `0x20` in a selected device/slot field. Bit meanings are not resolved by these accessors. [Findings 363](363-geometry-string-lookup-and-entity-state-helpers.md), [377](377-callback-registry-and-runtime-helpers.md), and [386](386-spatial-ui-com-and-crt-runtime.md) record the underlying operations.

`SimCursorInteractionTick @ 0x0045adb0` performs the in-game cursor interaction step: it asks `SimCategoryCellHitTest @ 0x0045b310` to find the hovered category/item, updates interaction state and dispatches the selected action, and falls back to the track-region test on a category miss. `RectContainsOffsetPoint @ 0x0045b590` supplies the rectangle test used by the category walk. `RegionContainmentScanUpdate @ 0x0045d110` separately checks configured region bounds, updates them through `RegionBoundsSet @ 0x0045d370`, and routes a changed match through priority/region helpers. See [Finding 240](240-cursor-interaction-overlay-menu-and-scene-light-helpers.md) and [Finding 245](245-region-route-light-config-and-surface-helpers.md). The names and hit-test roles are directly supported by those traces; the application-specific meaning of the region identifiers remains unknown.

## Camera and cursor controls

`PanelRotationControlConfigLoad @ 0x0045b9d0` reads the `PanelRotationControl` center, radius, and four image resources into globals. `PointDistanceWithinRadius @ 0x0045b8a0`, `IntegerPairDivideToFloatPair @ 0x0045b900`, and `FloatPairToIntegerPair @ 0x0045b930` provide distance and coordinate-conversion operations used by cursor geometry. `CameraDragFromCursorApply @ 0x0045bcd0` hit-tests the configured drag anchor, converts the pointer delta, and applies camera tilt/pan while setting direction bits; `CameraZoomStepAdjust @ 0x0045bf20` maps direction 0/1 to a signed zoom delta. `UIEntryBoundsGet @ 0x0045bf70` returns an entry's origin and computed width/height. The direct camera path and caller are documented in [Finding 247](247-config-graphics-camera-tween-and-pool-spawn-helpers.md); coordinate helpers are described in [Findings 354](354-record-vector-and-resource-state-helpers.md), [363](363-geometry-string-lookup-and-entity-state-helpers.md), [374](374-terrain-interface-and-media-helpers.md), [370](370-screen-effects-surface-and-ui-helpers.md), and [375](375-entity-ui-and-render-tree-helpers.md).

`PointerCursorNameRegistryInit @ 0x45c830`, `PointerCursorConfigLoad @ 0x45ca70`, and `PointerCursorConfigParse @ 0x45cbd0` initialize the name registry and load/parse cursor configuration. `0x00500a9c` is the base of the 56-entry cursor resource-handle table; `IndexedGlobalValueGet_00500a9c @ 0x45cc10` reads a selected slot, while `GlobalValueGet_00500a98 @ 0x45cc60` reads the selected cursor index. `PointerCursorSelect @ 0x45cc20` selects a cursor unless a positive override is active; `PointerCursorOverrideSet @ 0x45cc40` stores the selected slot and duration; `PointerCursorOverrideTick @ 0x45cd90` decrements the duration; and `PointerCursorDraw @ 0x45cc70` draws the selected static or animated cursor. The reward-screen caller decrements the timer by a fixed unit per pump iteration, so that path measures override duration in iterations, not proven elapsed time. See [Findings 103](103-pointer-cursor-config-registry.md) and [104](104-pointer-overrides-expire-in-the-reward-pump.md).

## Panel resources and advisor UI

`ScrollInfoPanelInitialize @ 0x0045b740` creates scroll-state rectangles and registers the info-panel widget. `UiOverlayCreateConfiguredElement @ 0x0045b850` creates a configured type-11 UI element. `ThreeSurfaceResourcesLoadAndInitialize @ 0x0045bfb0` loads and initializes three surfaces. `PanelResourceLayoutStore @ 0x0045c340` stores resource handles, dimensions, and offsets; `PanelResourcePositionUpdateIfEnabled @ 0x0045c4b0` applies a configured surface when enabled; and `PanelResourceHandleAndDimensionsStore @ 0x0045c520` stores its handle and dimensions. `GlobalValueSet_0050080c @ 0x0045c4a0` stores a value in a global whose meaning remains unknown. Existing traces are in [Findings 262](262-scroll-panel-and-viewport-picking-helpers.md), [375](375-entity-ui-and-render-tree-helpers.md), and [386](386-spatial-ui-com-and-crt-runtime.md).

`CrystalQuotaSetup @ 0x0045c040` reads `Quota.Crystals` and caps the display budget at 26; the reward-task field context is documented in [Finding 09](09-reward-task-manager.md). `PairCountHistogramBuild @ 0x0045c0d0` shifts a fixed pair table and builds a six-row value/count histogram. `AdvisorProgressBarFillDraw @ 0x0045c3f0` clamps progress to 100, computes a fill width from category-3 bounds, and submits a render helper call. `UiOverlayAnimationAdvance @ 0x0045c580` moves a global interpolation value toward an endpoint, while `UiOverlayAnimationApply @ 0x0045c5f0` computes coordinates from that value and sends them to the renderer. `AdvisorAnimationSceneLookupAndRequest @ 0x0045c670` resolves an animation slot and requests its scene action on success; `AdvisorAnimationSlotIdResolve @ 0x0045c6b0` maps a category/sub-index pair to observed slot IDs, returning false for unsupported pairs. See [Findings 258](258-interface-method-wrappers-overlay-refresh-and-deferred-set-relays.md), [271](271-panel-layout-and-advisor-render-helpers.md), and [375](375-entity-ui-and-render-tree-helpers.md). The two advisor-animation helpers are described from their direct pseudocode in `LEGORR.full.c`; caller context includes the advisor path's call to `AdvisorAnimationSceneLookupAndRequest`.

## Priority panel and region state

`PriorityListButtonActionDispatch @ 0x0045b620` maps button actions 0–8 to per-entry toggles and 9–16 to list reordering; `ConfigEntryEnabledToggleAtIndex @ 0x0045d4f0` bounds-checks and toggles an entry, with notifications for entries 0 and 1. `PriorityImagesConfigLoad @ 0x0045cdc0`, `PrioritiesConfigLoad @ 0x0045cf50`, and `PrioritiesImagePositionsConfigLoad @ 0x0045d060` load priority image, kind/weight, and position configuration. `PriorityLabelLayoutApply @ 0x0045cf00` applies saved label coordinates and visibility. `PriorityImageSelectionStateUpdate @ 0x0045d300` records a selected category/sentinel after hit testing; `PriorityPanelRowMoveDispatch @ 0x0045d3c0` selects a row move/swap operation from mode bits; `PriorityImageOrderMoveToFront @ 0x0045d3f0` shifts the priority-order table and refreshes positions; and `UIListEntriesSwap @ 0x0045d470` swaps entries and refreshes their displayed positions. Action IDs and some resulting render effects remain unresolved. See [Findings 250](250-config-band-loaders-cell-corner-scan-action-command-record-instantiation-and-render-state-helpers.md), [254](254-command-sweeps-cell-issuing-config-priorities-statistics-and-directdraw-create-helpers.md), [271](271-panel-layout-and-advisor-render-helpers.md), [274](274-priority-image-selection-and-scene-registry-teardown.md), [276](276-additional-engine-ui-and-scene-helper-names.md), [370](370-screen-effects-surface-and-ui-helpers.md), [372](372-incident-messages-options-and-resource-helpers.md), and [386](386-spatial-ui-com-and-crt-runtime.md).

`UiCursorMoveToChoiceEntry @ 0x0045d550` maps a choice to its selected item geometry and positions the cursor there; `UiCursorMoveToElementCenter @ 0x0045d640` positions it at an element's center. `PositionTrackerUpdateAll @ 0x0045d6d0` updates the positional-tracker entries from the engine tick; [Findings 03](03-engine-tick.md) and [254](254-command-sweeps-cell-issuing-config-priorities-statistics-and-directdraw-create-helpers.md) identify its tracker and drawing callers.

## Identifier remapping and coordinate setup

`LevelIdentifierRemapTableLoad @ 0x0045d7e0` reads identifier pairs from a config child list and stores a global remap table; the identifier domain and capacity are unresolved. `CommandEntityReferenceRemap @ 0x0045d870` applies the observed entity-reference remapping operation. `ObjectField14Set @ 0x0045d8a0` stores the supplied value at object offset `+0x14`. `ScreenCoordNormalizeInit @ 0x0045d8b0` normalizes a float table, initializes seven coordinate pairs against the current 640×480 screen dimensions, and sets its initialization markers. See [Findings 278](278-simulation-and-terrain-helper-names.md), [10](10-entity-command-primitives.md), [386](386-spatial-ui-com-and-crt-runtime.md), and [247](247-config-graphics-camera-tween-and-pool-spawn-helpers.md).

Taken together, the strongest direct flow is input/cursor position → category or region hit testing → interaction/action or camera update → panel/cursor/priority presentation. The exact meanings of several state bits, quota fields, remap identifiers, and UI table entries remain open. Useful follow-up slices are the action-ID table behind the priority buttons, the consumer of `DAT_0050080c`, and the source of the advisor category/sub-index pairs.

Complete pseudocode is in [LEGORR.full.c](../decompiles/full/LEGORR.full.c); named excerpts are in [engine-region.c](../decompiles/legacy/engine-region.c). This finding synthesizes existing address-level maps and caller traces; it does not claim new direct evidence-bundle records.
