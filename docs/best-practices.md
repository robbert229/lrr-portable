# Recovered-layout recommendations

The LEGO Island Decompilation Project maintains recommendations and examples
for documenting recovered class and structure sizes, member offsets, virtual
table entries, and unknown scalar types in [reccmp's recommendations](https://github.com/isledecomp/reccmp/blob/master/docs/recommendations.md).

This page points to that source rather than duplicating its text. Follow the
upstream document for its canonical wording and examples.
