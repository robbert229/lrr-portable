## Load row correction, 2026-11-04

The earlier statement that `SaveMenuBuild` builds six rows was incorrect: the loop advances from `0x557080` to `0x557418` by `0xb8`, exactly five rows. `SavRefreshSlots` separately refreshes six raw contexts. Static `MenuMouseCoordinateUpdate` returns the zero-based list index, `MenuInputTick` passes it unchanged to `SaveMenuRefresh`, and that calls `SavSetSlot`. Thus displayed rows 1–5 select raw contexts 0–4; context 5 remains available to the checkpoint fallback.
