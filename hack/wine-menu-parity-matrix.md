Explain drift before using a binary; retain prior and diagnostic artifacts. Bind each capture and process to the same frozen candidate; rerun affected contracts after any change. Verify active configuration actually uses /O2 /Ob1, not merely that cache contains those strings.

Before each launch: task flock and existing mutex, capacity preflight, no protected writers, independent complete authenticated stopped snapshots of reference and owned prefix, exact baseline equality, and fail-fast guard. Use the owned isolated X11 seat, ordinary sequential input, identified process/window/client/foreground and ready helper; no injection, direct start, retired prefix or real desktop changes. Record absent paths, writer cleanup and seat cleanup. Do not read protected live files with ordinary atime-changing reads or recursively scan archives.
