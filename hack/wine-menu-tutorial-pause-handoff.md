## Reference static save chain and scope

The retail binary evidence cited in [finding 08](../docs/findings/08-save-and-checkpoints.md), [finding 44](../docs/findings/44-reward-buttons-use-separate-save-routes.md), [finding 105](../docs/findings/105-sav-write-ignores-short-write-results.md), and [finding 408](../docs/findings/408-save-slot-context-and-level-record-lifecycle.md) establishes these static paths:

- `CheckpointStep` `0x462270` maps the level to a record, conditionally marks it, copies checkpoint data, and calls `SavCommit` `0x417fc0`. If there is no active slot it initializes slot 5. Reward Advance `0x461dd0` and a separate input path `0x462780` call it; reward Save instead enters conditional modal `0x462030`. These known paths do not establish which path ran during the retained tutorial route.
- `SavCommit` obtains the active context and calls `SavWriteSlot` `0x417bd0`. The existing-context update writes the `.sav` header and records, then calls `OsfWrite` `0x4593e0` for `Saves\%i.osf`; initialization uses a different header path. Option context is included in the update header ([finding 67](../docs/findings/67-save-slot-write-includes-option-context.md)). Return values do not establish complete writes. The observed `Data/Saves` resolution is a runtime fact of this setup, not a change to the static path string.
- `LevelLoad` `0x429890` calls `OsfRead` `0x459470` only for a clean in-memory table and active slot. This is a read path, including on reload; it does not itself prove a write. The cited findings do not prove a commit specifically at mission entry, return to picker, or process quit. Identify additional callers before attributing any of those transitions.

The afterstate proves an interval effect between the stopped baseline and final archive only. The file change and sidecar creation are consistent with the context-update chain, but that chain is not identified as the actual runtime caller. A new paired experiment should use separately restored stopped transactions ending after progressively later milestones (picker only; mission entry/briefing; pause and resume; pause Quit to picker; main Quit), retaining and comparing full afterstates and absent paths each time. These are distinct executions, so differences narrow the interval but do not prove instruction-level causation; keep settings, timing and input controlled and document side effects.
