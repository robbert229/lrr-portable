# Flat (non-COM) seam functions LegoRR.exe imports (finding 15 §1; `python3
# tools/seamrec/pe.py imports reference/LegoRR.exe`), signatures as in the
# mingw-w64 headers. gen.py checks each one against the header prototype.
#
#   proxy <dll>   functions exported by the proxy <dll>.dll beside the exe;
#                 every other export of the real DLL is passed through.
#   iat <DLL>     functions patched in LegoRR.exe's own import table.
#   ... hook      the wrapper calls SRH_<name> (hooks.c) instead of the real
#                 function: time, input, message and random-vector injection.
#
# Not wrapped: USER32 wsprintfA (varargs, pure formatting), and KERNEL32
# apart from Sleep and ExitProcess (file I/O, heap, CRT startup).
